 Database Setup
The database has been setup for anyone to recreate in a very simple manner.
Database name is 'nc_plus_one'.
db/setup.sql creates the database, tables and adds a placeholder for the table titles and values, all of which will be changed later.
To create this database please run 'psql -f db/setup.sql' in your terminal.
